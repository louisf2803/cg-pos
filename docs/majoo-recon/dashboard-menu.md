## Catatan umum
- Akun yang dipakai: Coffee Ground - Mangga Dua (Louis Ferdinand), data transaksi asli (Rp 786.450 harian saat
  ditelusuri 11 Nov 2026), jangan dianggap sebagai lingkungan uji — hanya dibaca, tidak diubah.
- "Appointment" tidak aktif di paket/akun ini (redirect ke halaman fitur tidak tersedia) — jadi menu appointment/
  reservasi jasa & fasilitas mungkin perlu akun paket lebih tinggi untuk dicoba penuh.
- Kuota karyawan & kuota admin dijual terpisah per paket (Default vs Berbayar) — model lisensi per-kursi.
