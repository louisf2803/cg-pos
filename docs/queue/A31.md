# A31 — Cetak barcode produk
Branch: ag/a31-barcode
Halaman baru /produk/barcode (tambahkan ke nav di grup Produk dengan tambahan minimal). Pilih produk (centang banyak, cari), jumlah label per produk, ukuran label (3 preset: 30x20, 40x30, 58 mm gulungan), isi label (nama, harga, SKU). Generator Code128 (set B) tulis sendiri sebagai fungsi murni di packages/shared/src/barcode.ts (kode -> array lebar bar) + tes (checksum, contoh baku). Pratinjau SVG di layar dan tombol 'Cetak' (window.print dengan CSS @media print yang hanya mencetak area label, kertas A4 grid atau gulungan). Kode memakai SKU produk; produk tanpa SKU ditandai tak bisa dicetak. Keadaan: kosong, memuat, galat, nama panjang dipotong 2 baris.
Wajib lulus: pnpm -r typecheck, pnpm -F @cgpos/shared test, pnpm -F @cgpos/dashboard build; Playwright 390/1280/1440 tanpa overflow/galat dan LIHAT screenshotmu sendiri (tes lulus belum berarti tampilan benar); screenshot ke docs/shots/a31/. Catat di docs/PROGRESS.md.
