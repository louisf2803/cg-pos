- Kasbon: `data.listCashAdvances(employeeId?)`, `saveCashAdvance` (hanya `BORROW` dan `PAYMENT_TRANSFER`), `deleteCashAdvance`. Entri `PAYMENT_PAYROLL` (potong gaji) dibuat otomatis saat periode gaji dikunci: tampilkan tetapi jangan beri tombol ubah/hapus. Saldo: `cashAdvanceBalances(list)`. Validasi: `cashAdvanceProblem`.
- Daftar karyawan dan gaji pokok: `data.listCompensation()`, `saveCompensation(...)` (status `permanent|probation|admin`, gaji pokok, uang makan, BPJS, cicilan kasbon per bulan). Validasi: `compensationProblem`.
