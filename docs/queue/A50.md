# A50 — Audit tabel dua kolom di 390 px (dashboard)
Branch: ag/a50-audit-tabel-390
Latar: `.cg-data` punya lebar minimum 520 px sehingga tabel dua kolom (label + jumlah) di 390 px mendorong kolom jumlah keluar layar; ini ketemu di arus kas tidak langsung (A34) dan diperbaiki dengan `style={{ minWidth: 0 }}`. Telusuri SEMUA halaman dashboard (apps/dashboard/src/app/**) yang memuat `<table className="cg-data` dengan 2 sampai 3 kolom (laporan keuangan: laba rugi, neraca, neraca saldo, hutang, arus kas langsung; laporan penjualan ringkas; pengaturan) dan perbaiki yang kolom pentingnya (jumlah/saldo) tidak terlihat di 390 px tanpa menggeser: matikan lebar minimum untuk tabel ≤3 kolom, biarkan label membungkus, jumlah `whitespace-nowrap`. Tabel lebar (≥4 kolom) tetap boleh menggulir mendatar. Jangan ubah CSS bersama di packages/ui; lakukan per tabel. Sertakan skrip Playwright yang memeriksa tiap halaman di 390 px: elemen jumlah terakhir pada tiap tabel harus berada di dalam viewport (getBoundingClientRect().right ≤ 390).
