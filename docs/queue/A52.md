# A52 — Denah & Meja: mode Grid vs Denah Kustom + pengaturan per meja
Branch: ag/a52-denah-kustom-meja
Latar: `/pengaturan/denah` (S32) sudah `built: true` (lantai + meja dikelola di dashboard, status Kosong/Terisi di kasir). Hasil penelusuran Majoo nyata (dashboard.majoo.id > Lainnya > Outlet > Pengaturan Denah dan Meja, 11 Nov 2026): ada DUA mode tampilan meja di POS — **"Grid Meja"** (grid sederhana, aktif di akun yang dicek) vs **"Denah Kustom"** (gambar/denah bebas). Per meja ada kolom yang bisa di-ON/OFF-kan satu-satu: **Batas Waktu** (durasi maksimum duduk), **Pengingat Waktu** (notifikasi sebelum waktu habis), **Minimum Tagihan** (nominal minimum per meja), **Label** (kolom label bebas per meja). `features.csv` catat ini di baris "meja: Mode meja dengan denah dan status berwarna" (belum: denah gambar bebas, batas waktu duduk) dan "meja: Denah meja kustom dengan drag posisi" (no) serta "meja: Batas waktu duduk dan pengingat per meja" (no).
Tugas: pada halaman `/pengaturan/denah` yang sudah ada, tambahkan:
1. Pemilih mode tampilan di atas: "Grid Meja" (bawaan, tampilan saat ini) vs "Denah Kustom". Simpan pilihan per outlet (cari metode DataLayer `saveOutletOptions`/`updateFloorMode` atau sejenis; bila tak ada, simpan di `localStorage` dengan lencana "Pratinjau" dan tulis permintaan di REQUESTS-FOR-CLAUDE.md).
2. Mode "Denah Kustom": kanvas sederhana (div relatif, bukan library berat) tempat tiap meja jadi kotak kecil yang bisa di-drag (pointer events, posisi x/y dalam persen agar responsif) dan diletakkan bebas; simpan posisi per meja (field baru di objek meja lokal/localStorage bila DataLayer belum punya `posX`/`posY` — tulis permintaan). Tombol "Simpan Posisi" dan "Reset ke Grid".
3. Per meja (baik mode manapun), tambahkan panel pengaturan dengan 4 toggle: Batas Waktu (bila aktif, muncul input menit), Pengingat Waktu (bila aktif, input menit-sebelum-habis, hanya aktif bila Batas Waktu aktif), Minimum Tagihan (input rupiah), Label (input teks bebas, maks 20 huruf). Simpan per meja.
4. Helper murni di packages/shared (`table-layout.ts`): validasi posisi dalam batas 0-100%, validasi batas waktu > pengingat waktu, format label. Tambahkan tes.
