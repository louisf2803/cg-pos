# A53 — Deposit: katalog paket deposit + laporan penjualan/refund deposit
Branch: ag/a53-deposit
Latar: Tiga baris stub di nav.ts belum dibangun: `/deposit` (S37, "Paket deposit", modul Produk), `/laporan/deposit` (S80, modul Laporan). `features.csv` baris "deposit: Paket deposit (beli saldo, pakai di POS)" = no sama sekali; ini satu-satunya area dengan skor 0.0 di laporan parity selain hr/reservasi/layar pelanggan/owner/customer app.
Tugas:
1. `/deposit` — Katalog paket deposit (mis. "Deposit 100rb", "Deposit 500rb") dengan kolom: nama paket, nominal yang didapat pelanggan, harga jual paket (boleh sama dengan nominal atau beda bila ada bonus, mis. "Beli 500rb dapat 550rb"), aktif/nonaktif. CRUD sederhana (tambah/ubah/nonaktifkan, tanpa hapus permanen bila sudah pernah terjual — cek dulu).
2. `/laporan/deposit` — dua tab: "Penjualan Deposit" (daftar transaksi pembelian paket deposit: tanggal, pelanggan, paket, nominal, metode bayar) dan "Refund Deposit" (daftar pengembalian saldo deposit: tanggal, pelanggan, nominal, alasan).
Cari dulu metode DataLayer (`listDepositPackages`, `listDepositSales`, dsb). Fitur ini genuinely belum ada sama sekali di data layer (dikonfirmasi oleh features.csv): JANGAN mengarang skema database atau alur pembayaran deposit penuh. Bangun halaman dengan data contoh statis di memori komponen (bukan localStorage, karena ini laporan, bukan preferensi) yang jelas berlabel "Pratinjau tampilan — menunggu dukungan server", dan tulis permintaan lengkap di `docs/REQUESTS-FOR-CLAUDE.md`: tabel `deposit_packages` (id, nama, nominal_didapat, harga_jual, aktif), `deposit_sales` (id, customer_id, package_id, nominal, metode_bayar, order_id, created_at), `deposit_refunds` (id, customer_id, nominal, alasan, created_at), serta metode `data.listDepositPackages()`, `data.saveDepositPackage()`, `data.listDepositSales(range)`, `data.listDepositRefunds(range)`.
Tujuan tugas ini adalah kerangka tampilan yang siap disambungkan Claude begitu tabel ada, bukan fitur deposit yang jalan penuh.
