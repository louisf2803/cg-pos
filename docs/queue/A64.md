# A64 — POS: Laporan Void dengan filter/detail & Riwayat Refund per transaksi
Branch: ag/a64-pos-void-refund
LINGKUP KHUSUS: apps/pos dan packages/shared (helper murni `pos-history.ts` + tes; JANGAN ubah `data.ts`, `supabase.ts`, `packages/db`, atau `features.csv`/`wave.csv`/`bugs.md`).

Fitur Gelombang A yang dikerjakan (`docs/SCOPE.md`):
- **Laporan void di POS dengan filter dan detail**
- **Riwayat refund per transaksi** (penjualan bersih, daftar refund, detail transaksi + riwayat refund per order di kasir)

Rincian:
1. Helper murni di `packages/shared/src/pos-history.ts` + tes (`packages/shared/test/pos-history.test.ts`), ekspor lewat `packages/shared/src/index.ts`:
   - `posSalesRange(tz, preset, now?)`: rentang UTC `'today' | '7d' | '30d'` menurut zona outlet (`Asia/Jakarta` dst.).
   - `groupRefundsByOrder(refunds)`: indeks refund per `orderId` (urut terbaru dulu + total nilai refund per transaksi).
   - `summarizePosSales(paidOrders, voidOrders, refunds)`: penjualan lunas, total refund, penjualan bersih, jumlah pesanan lunas, jumlah & nilai void.
   - `filterPosOrders(orders, query, opts)`: filter berdasar kata kunci (nomor, pelanggan, label, meja, kasir, item), kasir (`cashierId`), jenis order (`OrderType`), serta opsi `onlyRefunded`.
   - `filterPosRefunds(refunds, ordersById, query, methodFilter)`: filter daftar refund di POS berdasar nomor refund, nomor pesanan, alasan/catatan, kasir, serta metode pengembalian.
2. Perluas `apps/pos/src/screens/Sales.tsx` (tetap mempertahankan heading "Penjualan Hari Ini" untuk rentang `Hari ini`, serta kompatibilitas elemen `Total Penjualan` dan `Jumlah Transaksi`):
   - Pemilih rentang cepat (`Hari ini`, `7 hari`, `30 hari`), tab **`Penjualan`**, **`Void`**, dan **`Refund`**.
   - 4 KPI ringkas: Penjualan Lunas, Total Refund, Penjualan Bersih, dan Ringkasan Void (atau Transaksi).
   - Filter kasir (`listEmployees`), jenis pesanan, status refund (`Semua | Ada refund`), metode pengembalian, serta kolom pencarian kata kunci.
   - Klik baris / tombol `Rincian` pada tab Lunas, Void, maupun Refund membuka **Modal Rincian Transaksi**: waktu buka/tutup/batal, kasir, jenis order, nama meja/pelanggan/label, daftar item (beserta ekstra & catatan), rincian subtotal/potongan/biaya layanan/pajak/pembulatan/total, pembayaran, dan **Riwayat Refund Transaksi** via `data.listRefunds(order.id)`.
3. Perluas `apps/pos/src/screens/Orders.tsx`:
   - Pada panel rincian (`expandedId`), tampilkan kasir & waktu dibatalkan untuk order berstatus `void`, serta tampilkan **Riwayat Refund** (`data.listRefunds(target.id)`) langsung di panel rincian untuk order berstatus `paid` (dan lencana jumlah refund bila ada).
   - Tetap pertahankan semua label/testid/tombol yang diuji `scripts/trial-e2e.js`.
