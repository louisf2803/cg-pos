# A19 — Penerimaan dan Pengeluaran (keuangan)
Branch: ag/a19-biaya
Halaman /keuangan/biaya (sudah ada di nav, belum dibangun): dua tab "Penerimaan" dan "Pengeluaran". Tiap tab: daftar transaksi per rentang tanggal (useReport + RangePicker), kartu total, tombol "Catat penerimaan/pengeluaran" (dialog: tanggal, jumlah, akun lawan dari daftar akun, akun kas/bank, catatan). Simpan memakai fungsi jurnal manual yang SUDAH ADA di DataLayer (lihat data.ts: createJournal / daftar akun; jangan ubah data.ts/supabase.ts). Pengeluaran = debit akun beban, kredit kas/bank; penerimaan = debit kas/bank, kredit akun pendapatan lain. Helper murni + tes di packages/shared (cash-entry.ts) yang membentuk baris jurnal dan memvalidasi (jumlah > 0, akun dipilih, tanggal tidak di periode terkunci bila ada aturannya). Mobile: kartu daftar. Daftarkan di nav (built: true).
