# A65 — POS: Mode Tampilan Dapur (KDS) & Pengalih Mode Berdasar Hak Akses
Branch: ag/a65-pos-kitchen-mode
LINGKUP KHUSUS: apps/pos dan packages/shared (helper murni `kitchen.ts` + tes; JANGAN ubah `data.ts`, `supabase.ts`, `packages/db`, atau `features.csv`/`wave.csv`/`bugs.md`).

Fitur Gelombang A yang dikerjakan (`docs/SCOPE.md`):
- **Layar Pilih Karyawan dengan PIN setelah login perangkat; hak akses menentukan mode tampilan (kasir, dapur)**
- **Layar dapur (kitchen display) ... tampilan dapur penuh layar per stasiun**

Rincian:
1. Helper murni di `packages/shared/src/kitchen.ts` + tes (`packages/shared/test/kitchen.test.ts`):
   - `PosAppMode = 'register' | 'kitchen'`
   - `canSwitchPosAppMode(role)`: mengizinkan peran `owner` / `manager` (`Pemilik` / `Manajer`) berpindah bebas antara Kasir dan Layar Dapur, sementara `cashier` mengikuti mode perangkat yang ditetapkan manajer/pemilik.
   - `resolvePosAppMode(role, deviceMode, requestedMode?)`: menentukan mode awal POS setelah login PIN.
   - `filterKitchenTickets(tickets, { query?, lane? })`: filter tiket dapur menurut kata kunci (nomor pesanan, meja, label, antrean, nama/catatan/ekstra item) dan lajur status.
   - `ticketAdvancePlan(ticket)`: merencanakan aksi maju satu tahap untuk item pada lajur terawal tiket (`Mulai olah`, `Tandai siap`, `Sudah disajikan`).
2. `apps/pos/src/lib/device-prefs.ts` & `apps/pos/src/screens/DeviceSettings.tsx`:
   - Tambah `appMode: PosAppMode` (bawaan `'register'`) dan `kitchenStationId: string` (bawaan `'all'`) di `DevicePrefs`.
   - Di `DeviceSettings.tsx` (khusus manajer/pemilik): pemilih **Mode Aplikasi Perangkat** (`Kasir (POS)` vs `Layar Dapur (KDS)`) dan stasiun dapur bawaan dari `data.listPrintStations()`.
3. `apps/pos/src/screens/KitchenDisplay.tsx` (Layar Dapur Penuh POS):
   - Tampilan penuh layar dapur nyata memakai `data.kitchenBoard(servedMinutes)`, `data.kitchenSetStatus(itemIds, status)`, dan `data.listPrintStations()`.
   - Segar otomatis tiap 8 detik + tombol `Perbarui`, tombol `Layar penuh`, pengalih stasiun (`Semua Stasiun` / per stasiun), tab lajur (`Semua`, `Baru`, `Diproses`, `Siap`), pencarian tiket, toggle `Tampilkan Disajikan (60 mnt)`, tombol maju satu tahap per tiket & per item beserta tombol `Mundur` satu tahap, penanda waktu tunggu (`ok`/`warn`/`late`), dan tombol pindah ke Kasir & Pengaturan Perangkat (hanya untuk peran yang berhak).
4. `apps/pos/src/screens/Login.tsx`, `SideDrawer.tsx`, `Register.tsx`, & `App.tsx`:
   - Di `Login.tsx`: pemilih mode masuk (`Kasir` / `Layar Dapur`) yang merespons hak akses peran saat karyawan dipilih (`cashier` mengikuti setelan perangkat; manajer/pemilik bebas memilih mode).
   - Pada mode `'kitchen'` di `App.tsx`: langsung membuka `KitchenDisplay` tanpa memaksa `Buka kasir` (laci kas).
   - Di `SideDrawer.tsx` & `Register.tsx`: menu `Layar Dapur` tersedia untuk manajer/pemilik agar bisa berpindah langsung ke KDS dan kembali lagi ke Kasir.
