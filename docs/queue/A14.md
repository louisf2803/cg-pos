# A14 — Isi Dashboard Penjualan (beranda)
Branch: ag/a14-beranda
1. Header: judul + ikon ? + bintang favorit, "Diperbarui <tanggal jam>", tab Harian/Mingguan/Bulan, pemilih tanggal dengan panah ‹ › (geser sesuai tab). Ikuti pola useReport/RangePicker.
2. Helper murni packages/shared/src/period-compare.ts + test: periode sebelumnya, persen perubahan (sebelumnya 0 → 100% bila sekarang >0, 0 bila keduanya 0), akumulasi awal bulan, proyeksi akhir bulan. Uji tepi: Februari, pergantian tahun, pembagi nol. Ekspor di index.ts.
3. Kartu KPI: kiri Total Penjualan besar + persen + akumulasi awal bulan + proyeksi bulan ini; tengah Belum dibayar & Terbayar; kanan grid 2x2 Transaksi, Penjualan per transaksi, Produk terjual, Produk per transaksi. Persen naik hijau ↗, turun merah ↘.
4. Grafik per jam 00–23: SVG garis halus buatan sendiri (tanpa library), periode ini (hijau) vs sebelumnya (abu), legenda, sumbu Y rb/jt, tooltip hover/fokus keyboard, teks alternatif.
5. Grid widget (4 kolom ≥1280, 2 kolom ≥768, 1 kolom di bawah): Metode pembayaran, Void, Penjualan per kasir, Produk terlaris, Stok terendah (merah bila minus), Penjualan per kategori, Jenis order, Komisi per kasir (kosong: "Belum ada data komisi"). Tiap kartu: bar horizontal bulat + nilai, menu ⋯ (placeholder nonaktif), link "Lihat semua ›" ke laporan yang sudah ada.
6. Data hanya dari DataLayer yang ada (listOrders, listStock, listOutlets, dst) lewat useAsync; filter outlet mengikuti pemilih sidebar.
