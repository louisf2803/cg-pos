# A16 — Daftar Karyawan (tampilan)
Branch: ag/a16-karyawan
Halaman /pengaturan/karyawan: pertahankan semua fungsi yang ada (tambah, ubah, atur PIN, nonaktifkan, matriks hak akses) — jangan ubah perilaku atau alur PIN. Perapian tampilan: kartu kuota di atas (total, terpakai, tersisa untuk karyawan dan admin, dihitung dari data karyawan), pencarian + filter status, tabel dengan kolom nama+kode, posisi/peran, outlet, status, menu ⋯; tombol "Ringkasan outlet" (modal: jumlah karyawan per outlet). Mobile: daftar kartu, bukan tabel lebar. JANGAN menampilkan atau menyimpan PIN dalam bentuk apa pun.
