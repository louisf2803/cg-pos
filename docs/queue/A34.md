# A34 — Arus kas metode tidak langsung
Branch: ag/a34-arus-kas-tidak-langsung
Di halaman Laporan arus kas (cari di /laporan atau /keuangan), tambah tab 'Langsung | Tidak langsung'. Metode tidak langsung: mulai dari laba bersih periode, tambah/kurang penyesuaian (perubahan piutang, persediaan, hutang usaha dari saldo akun awal vs akhir periode yang sudah tersedia di data buku besar/neraca), hasilkan arus kas operasi; lalu arus investasi dan pendanaan bila akunnya ada (kalau tidak ada tampilkan baris 0). Fungsi murni di packages/shared (cashflow-indirect.ts) + tes dengan contoh angka yang rekonsiliasinya terbukti (total = perubahan kas). Jelaskan di UI satu kalimat bila ada penyesuaian yang tidak bisa dihitung.
Wajib lulus: pnpm -r typecheck, pnpm -F @cgpos/shared test, pnpm -F @cgpos/dashboard build; Playwright 390/1280/1440 tanpa overflow/galat dan LIHAT screenshotmu sendiri (tes lulus belum berarti tampilan benar); screenshot ke docs/shots/a34/. Catat di docs/PROGRESS.md.
