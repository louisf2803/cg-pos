# A35 — Notifikasi stok di dashboard (lonceng)
Branch: ag/a35-notifikasi-stok
Ikon lonceng di topbar sudah ada tanpa fungsi. Aktifkan: panel (popover) berisi ringkasan notifikasi stok dari data.listStock: Habis (0), Minus (<0), Di bawah minimum; tiap baris tautan ke halaman stok dengan filter terkait; lencana jumlah di lonceng; tandai 'sudah dilihat' disimpan di localStorage per hari. Segarkan tiap 60 detik saat tab terlihat. Fungsi murni pengelompokan di packages/shared (stock-alerts.ts) + tes. Keyboard: Escape menutup, fokus kembali ke lonceng. Keadaan: tidak ada notifikasi (pesan ramah), galat, memuat.
Wajib lulus: pnpm -r typecheck, pnpm -F @cgpos/shared test, pnpm -F @cgpos/dashboard build; Playwright 390/1280/1440 tanpa overflow/galat dan LIHAT screenshotmu sendiri (tes lulus belum berarti tampilan benar); screenshot ke docs/shots/a35/. Catat di docs/PROGRESS.md.
